# Contributing Guidelines

Thank you for considering contributing to Axiora OS!

## Getting Started
- Fork the repository.
- Clone your fork locally.
- Create a new branch for your feature or bug fix.
- Make sure the code builds and passes all tests.
- Submit a Pull Request with a clear description.

## Coding Style
- TypeScript: follow the Airbnb style guide, use Prettier.
- Rust: follow `rustfmt` defaults.
- Use meaningful commit messages.

## Testing
- Run `cargo test` for Rust services.
- Run `npm test` for the shell UI.
