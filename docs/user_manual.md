# Axiora OS User Manual

Welcome to Axiora OS, the fast and beautiful desktop experience.

## Getting Started

1. **Booting Up**: After installation, your system will boot into the Axiora Shell in under 15 seconds.
2. **Login**: Select your user account and enter your password. The system uses Wayland for a smooth experience.

## Desktop Interface

- **The Dock**: Located at the bottom of the screen (customizable). Pin your favorite apps here.
- **The Launcher**: Press the `Super` key to open the application launcher and search through apps, settings, and files.
- **Notification Center**: Click the top-right corner to see notifications and access quick settings (WiFi, Bluetooth, Volume, Focus Mode).

## Customization

Open **Settings > Appearance** to customize:
- Accent Colors (Blue, Purple, Green, Orange, Red)
- Dark Mode / Light Mode
- Wallpapers

## Focus Mode

Toggle "Focus Mode" from the Quick Settings to block distractions. This will silence notifications and hide non-essential alerts for a set duration.

## Workspaces

Switch between Workspaces using the multitasking view. You can also apply **Workspace Profiles** (e.g., Study, Development) to change the layout and pinned apps based on your current task.
